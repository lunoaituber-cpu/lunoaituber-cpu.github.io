Privacy Policy

Luno SNS Analytics

Last updated: October 14, 2026

1. Overview

Luno SNS Analytics is a tool for analyzing social media performance associated with the AI Tuber Luno.

The tool is intended for internal testing, authorized account management, and performance analysis, not general public use.

YouTube data collection has been implemented. TikTok integrations are still under development.

2. Information We Access or Plan to Access

YouTube

With authorization from the relevant Google account holder, the tool uses the YouTube Data API v3 and YouTube Analytics API to access information about the authorized YouTube channel, including:

  • Channel identification and basic channel information
  • Subscriber count
  • Channel view statistics
  • Published video information and video count
  • Available daily and historical video or channel analytics

Google OAuth is used to authorize API access. The tool accesses data within the permissions granted by the account holder.

TikTok

With the TikTok account holder's authorization, the tool may access information permitted by TikTok API scopes, including:

  • Basic account information needed for authorization
  • Follower count and account statistics
  • Public video information and video statistics

These TikTok integrations are still being developed. This section describes planned access, not currently operating TikTok data collection.

3. Purpose of Data Use

Authorized data is used to record daily statistics, review historical trends, and evaluate the performance of Luno's social media activities.

YouTube statistics are collected for internal reporting and recorded in local management files.

TikTok data collection remains under development.

4. Storage and Security

Collected YouTube statistics are stored in local management files, including Excel workbooks. Local backups may be created to protect existing records during updates.

OAuth authentication credentials are maintained separately from the published website and analytics records.

API credentials, access tokens, refresh tokens, and client secrets are not intended to be published on this website or in public source code.

TikTok storage and security procedures will be reviewed as its integrations are activated.

5. Sharing of Information

The tool is intended for internal use. Selling account data or providing account data to advertisers is not part of the service.

Information may be processed by Google, YouTube, TikTok, and relevant infrastructure providers as required for authorized operations and subject to their applicable policies.

YouTube API Services are used by this application. Users can review the YouTube Terms of Service and the Google Privacy Policy .

6. Data Retention and Deletion

Collected records are retained for internal analysis and historical comparison. A fixed retention period has not yet been established.

The project operator manages the deletion of locally stored records and authentication credentials. Requests about stored information can be directed to the project operator.

Google account holders can review or revoke access granted to this application through Google Account connections . TikTok access may be revoked through TikTok account settings where supported.

Revoking API access does not automatically guarantee deletion of locally stored historical records.

7. Changes to This Policy

This policy will be updated as the tool's actual data handling practices are established or changed.

8. Contact

For privacy-related questions, please refer to the contact information on the official Luno SNS Analytics website .
