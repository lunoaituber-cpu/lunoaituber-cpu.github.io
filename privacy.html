Privacy Policy

Luno SNS Analytics

Effective date: October 11, 2026

1. Overview

Luno SNS Analytics is an experimental tool under development for analyzing social media performance associated with the AI Tuber Luno.

The tool is currently intended for internal testing and account management, not general public use.

2. Information We Plan to Access

With the TikTok account holder's authorization, the tool may access information permitted by TikTok API scopes, including:

  • Basic account information needed for authorization
  • Follower count and account statistics
  • Public video information and video statistics

These integrations are still being developed. This section describes planned access, not currently operating data collection.

3. Purpose of Data Use

The planned use of authorized data is to record daily statistics, review historical trends, and evaluate the performance of Luno's social media activities.

4. Storage and Security

The tool is being designed to store authorized statistics and authentication credentials separately. Specific storage and security measures will be reviewed before the integration is activated.

TikTok access tokens and client secrets will not be intentionally published on this website or in public source code.

5. Sharing of Information

The tool is currently intended for internal use. Selling account data or providing account data to advertisers is not part of the planned service.

Data may be processed by TikTok and infrastructure providers as necessary for authorized operations, subject to their applicable policies.

6. Data Retention and Deletion

Data retention periods and deletion procedures will be established before production use. Authorized access can be revoked through TikTok account settings where supported.

Revoking access does not necessarily delete data previously stored by an application. Requests regarding stored information will be handled by the project operator.

7. Changes to This Policy

This policy will be updated as the tool's actual data handling practices are established or changed.

8. Contact

For privacy-related questions, please refer to the contact information on the official Luno SNS Analytics website .
