🌙 Luno SNS Analytics

Social media analytics tool for the AI Tuber Luno.

About

Luno SNS Analytics is an experimental tool being developed to organize social media performance data in one place.

Planned Features

  • Track TikTok follower and video statistics.
  • Record daily account performance.
  • Review historical trends and growth.

Development Status

This project is currently under development. TikTok API integration is being evaluated in a sandbox environment.

Privacy

This website does not collect visitor information through forms or custom analytics scripts. A separate privacy policy will be provided before any public application launch.
