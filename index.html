🌙 Luno SNS Analytics

Social media analytics tool for the AI Tuber Luno.

About

Luno SNS Analytics is an experimental tool for organizing and reviewing social media performance data associated with the AI Tuber Luno.

The tool is intended for internal testing, authorized account management, and performance analysis. It is not currently a public service.

Features

  • Collect authorized YouTube channel statistics using the YouTube Data API v3 and YouTube Analytics API.
  • Record available daily YouTube statistics in local management files.
  • Review historical performance trends.
  • Explore TikTok follower and video statistics through integrations under development.

Development Status

YouTube analytics collection has been implemented. Its current authorization issue is being investigated.

TikTok API integration is being evaluated in a sandbox environment and is not currently operating as a production data collection service.

Privacy and Terms

This website does not currently use forms or custom analytics scripts to collect visitor information. Data accessed through authorized API integrations is described in the Privacy Policy.
