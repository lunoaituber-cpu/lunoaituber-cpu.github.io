1. About the Service

Luno SNS Analytics is a software tool for organizing and reviewing social media performance data associated with the AI Tuber Luno.

The tool is intended for internal testing, authorized account management, and performance analysis. It is not currently offered as a public service.

YouTube analytics collection has been implemented. TikTok API integrations remain under development.

2. Authorized Use

The tool accesses YouTube channel information and analytics only with authorization from the relevant Google account holder and within the permissions granted through Google OAuth.

The tool uses the YouTube Data API v3 and YouTube Analytics API for authorized channel statistics and performance analysis.

TikTok integrations are intended to access TikTok account information only with the account holder's authorization and within the permissions granted through TikTok.

Use of the tool must comply with applicable laws, Google's applicable API policies, the YouTube Terms of Service , and TikTok's relevant terms and policies.
